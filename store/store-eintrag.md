# Play-Store-Eintrag – Smash Burger

**App-Name (max. 30):** Smash Burger – Kartenspiel

**Kurzbeschreibung (max. 80):**
Bau deine Burger, klau die der anderen – das Online-Kartenspiel für 2–6 Freunde!

**Vollständige Beschreibung:**

Bereite deinen Burger zu. Smashe die Konkurrenz! 🍔

In diesem Restaurant gibt es nur eine Mission: Stell als Erste:r alle Burger der Speisekarte fertig – und mach dabei die Burger der anderen platt. Wer trödelt, wird gesmasht!

🍔 SO EINFACH GEHT'S
• Tisch eröffnen, Code oder Link an Freunde schicken – fertig.
• Jede:r spielt auf dem eigenen Handy, egal ob nebeneinander auf dem Sofa oder quer durchs Land.
• Spiele pro Zug 1 bis 3 Karten: Zutaten legen, Karten abwerfen oder Chaos stiften.

🔥 AKTIONSKARTEN
• Anbrennen: Verbrenne einen beliebigen Burger – ab in den Müll!
• Klauen: Schnapp dir einen fertigen Burger oder die oberste Zutat.
• Mülltaucher: Fisch dir eine Zutat aus dem Müll.
• Falscher Tisch: Alle Tabletts wandern eine Person weiter.

👯 Zwei gleiche Karten auf der Hand? Wirf sie ab und zieh blind eine Karte von jemand anderem!

✨ FEATURES
• 2–6 Spieler:innen, ca. 20 Minuten pro Runde
• Zu wenige Leute? Hol dir Bots an den Tisch
• Die App zeigt dir immer, wo deine Karte hinpasst – Regeln lernen in einer Runde
• Kein Konto, keine Anmeldung, keine Werbung

Los geht's – ab in die Küche!
